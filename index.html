Cómo dibujar

  1. Elige una herramienta (p. ej. Línea).
  2. Haz clic en el lienzo para iniciar y clic para fijar.
  3. Polilínea: clic por cada vértice y doble clic para terminar.
  4. Arco: clic = centro, clic = inicio, clic = fin.
  5. Usa Seleccionar (🖱) para mover objetos.
  6. Las propiedades (capa, color, tipo, grosor) se aplican a lo que dibujes.
  7. Arrastra una computadora desde abajo para ubicarla.
